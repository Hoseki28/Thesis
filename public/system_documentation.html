1. Executive Summary & System Objectives

The Padayon B-TEG Core is an off-grid hybrid renewable energy harvesting and monitoring system designed to recover high-enthalpy thermal waste from domestic biomass cookstoves and convert it directly into regulated direct current (DC) electrical power.

Traditional rural biomass combustion expels upwards of 75% to 85% of chemical fuel energy as ambient thermal waste. The B-TEG system utilizes solid-state thermoelectric generator (TEG) modules sandwiched between the stove combustion chamber and an active cooling heat exchanger. Concurrently, an integrated Internet of Things (IoT) edge device (ESP32) samples real-time physical telemetry and transmits high-frequency telemetry packets to a local Progressive Web App (PWA) running on mobile phones, tablets, or laptops.

2. Thermodynamic Principles & The Seebeck Effect

The physical foundation of solid-state thermoelectric generation is the Seebeck Effect, where a temperature differential ($\Delta T$) across dissimilar doped semiconductors (p-type and n-type bismuth telluride, $Bi_2Te_3$) establishes an electromotive force (voltage).

V_oc = N · α · (T_hot - T_cold) = N · α · ΔT

Where:

  • V_oc = Open-circuit voltage generated by the TEG array (Volts).
  • N = Number of individual thermoelectric thermocouple junctions in series.
  • α = Differential Seebeck coefficient ($\approx 200\,\mu\text{V}/\text{K}$ per junction).
  • T_hot = Temperature of the stove wall hot junction (measured via MAX6675).
  • T_cold = Temperature of the cooling heat sink (measured via DHT11).
  • ΔT = Net thermal gradient across the semiconductor ceramic faces.

Internal Resistance & Maximum Power Transfer

According to Jacobi's law (Maximum Power Transfer Theorem), maximum power ($P_{max}$) is harvested when the electrical load resistance ($R_{load}$) matches the internal resistance ($R_{int}$) of the TEG array:

P_max = (V_oc)^2 / (4 · R_int)

Under experimental operation, thermoelectric output begins generating measurable potential once $\Delta T > 40^\circ\text{C}$. When stove temperatures reach nominal operational levels ($180^\circ\text{C}$ to $240^\circ\text{C}$) against ambient cold temperatures of $28^\circ\text{C}$, the system produces a $\Delta T$ of $150^\circ\text{C}$ to $210^\circ\text{C}$, sustaining electrical output sufficient to charge the secondary storage battery.

4. Power Conditioning, Storage & Automated Load Shedding

The raw electrical energy delivered by thermoelectric modules fluctuates according to combustion rate and thermal gradients. A high-efficiency DC-DC Step-Up Boost Converter (XL6009/MT3608 topology) steps up raw TEG voltages ($3.5\text{V} - 8.5\text{V}$) to a nominal $13.8\text{V}$ float voltage for battery bank charging.

Battery State of Charge (SoC) Calculation

The battery state of charge is monitored continuously using a calibrated transfer curve across the voltage boundaries:

SoC (%) = [ (V_batt - V_min) / (V_max - V_min) ] × 100

Where default calibrated thresholds are set to $V_{min} = 10.50\text{V}$ (0% discharge cutoff) and $V_{max} = 13.80\text{V}$ (100% full saturation).

Automated Load Shedding Interlock

To prevent destructive deep-discharge cycles that degrade lead-acid and lithium battery cells, the system features an Automated Load Shedding Interlock:

  • Cutoff Protection: If the battery State of Charge falls to or below 20% ($11.16\text{V}$), the firmware and dashboard immediately disengage non-critical secondary loads (cooling fans and auxiliary outputs).
  • Emergency Lighting Lock: The emergency lighting bus remains isolated on a dedicated power rail to guarantee essential illumination during off-grid nighttime usage.
  • Thermal Recovery: Once the stove core heats up and TEG power re-establishes a net-positive charging current, loads are re-enabled safely.

5. ESP32 Firmware Architecture & Communication Protocols

The system implements a Universal Triple-Transport Bridge enabling the ESP32 to communicate with any host device without external cloud dependencies:

1. Wired USB Serial (Web Serial API)

Operates over native micro-USB / Type-C UART at 115200 baud, 8-N-1. Supported natively in desktop browsers (Chrome, Edge, Opera) via the W3C Web Serial API. Enables hardware-in-the-loop debugging with zero wireless overhead.

2. Bluetooth Low Energy (Web Bluetooth API)

Utilizes the industry-standard Nordic Semiconductor UART GATT Service. Allows Android smartphones and PC browsers to pair directly over BLE without installing native apps from Google Play:

  • Service UUID: 6e400001-b5a3-f393-e0a9-e50e24dcca9e
  • RX Characteristic (Write to ESP32): 6e400002-b5a3-f393-e0a9-e50e24dcca9e
  • TX Characteristic (Notify to Dashboard): 6e400003-b5a3-f393-e0a9-e50e24dcca9e

3. Wi-Fi Local WebSocket Protocol

The ESP32 broadcasts a localized SoftAP (e.g. Padayon-ESP32) or joins a local WLAN, running an embedded asynchronous WebSocket server on port 81 (`ws://:81/ws`). Ideal for iPhones (iOS Safari) where Web Bluetooth is restricted.

JSON Telemetry Protocol Specification

Every 1000 milliseconds, the ESP32 constructs a compact, high-efficiency JSON telemetry packet terminated by a newline character (\n): 

{
  "stoveTemp": 185.2,
  "ambientTemp": 28.5,
  "humidity": 68,
  "batteryV": 13.20,
  "tegVoltage": 5.20,
  "tegCurrent": 1.15,
  "relays": {
    "dcBus": 1,
    "lights": 1,
    "fans": 1,
    "aux": 0
  }
}

6. PWA Telemetry Dashboard & Frontend Architecture

The client interface is engineered using React 19, TypeScript, and Tailwind CSS v4, packaged as a high-performance Progressive Web App (PWA):

Key Dashboard Components

  • Live Precision AM/PM Digital Clock: Ticking digital chronometer synchronized with Philippine Standard Time (PHT, UTC+8) with non-military format (`8:45:12 PM PHT • Fri, Oct 2`).
  • Single Canonical Connection Hub: A unified connection pill button in the top status bar launching a multi-transport pairing modal with live packet counters, round-trip latency measurement ($ms$), and signal strength RSSI.
  • Overview Tab: Real-time gauge metrics showing Stove Core Temperature, Cold Sink Temperature, Delta-T ($\Delta T$), Battery Voltage, Battery Percentage, TEG Output Power, and System Health.
  • Sensors Tab: Granular diagnostic view displaying raw ADC counts, calibrated physical values, and individual sensor transfer statuses.
  • Calibration Studio: Interactive slider studio allowing researchers to tune thermal gains, sensor offsets, and battery voltage thresholds with instant non-volatile localStorage persistence.
  • System Logs Component: Real-time event log buffer (capped at 50 max entries) with dynamic YYYY-MM-DD HH:mm PHT timestamps, color-coded level cards (Info, Warning, Error), category filtering, smooth auto-scroll, and 1-click CSV dataset export.

8. Field Deployment, Mobile Access & Operating Instructions

A. Running on Mobile Phone (Android)

  1. Open Google Chrome on the Android device.
  2. Navigate to the live production URL: https://design-energy-dashboard-pwa.vercel.app
  3. Tap the Chrome menu (⋮) and select "Add to Home screen" or "Install app" to install as a full-screen PWA.
  4. Tap [● CONNECT ESP32] in the header bar.
  5. Select the Bluetooth (BLE) tab and tap PAIR VIA BLUETOOTH.
  6. Select Padayon-ESP32 from the device picker. The dashboard will instantly stream live telemetry without needing any cables.

B. Running on iPhone (iOS)

  1. Wi-Fi Method: Connect your iPhone to the ESP32's Wi-Fi hotspot (`Padayon-ESP32`). Open the dashboard in Safari, click Wi-Fi in the Connection Modal, enter `192.168.4.1`, and connect.
  2. Bluetooth Method: Install the free Bluefy – Web BLE Browser from the App Store, navigate to the URL, and pair via Bluetooth.

C. Exporting Telemetry for Thesis Data Analysis

The dashboard features two dedicated data export mechanisms:

  • Telemetry Sensor CSV: Exports full time-series physical measurements (Stove Temp, Ambient Temp, Humidity, Battery Voltage, TEG Power) for graphing in MATLAB, Excel, or Python.
  • System Event Logs CSV: In the LOGS tab, click EXPORT CSV to download all edge-triggered threshold breaches, connection timestamps, and system status logs formatted with PHT local time.
